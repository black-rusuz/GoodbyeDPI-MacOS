# ByeDPI for macOS (автономный бандл с интеграцией в Launchpad)

Готовая сборка и лаунчер **ByeDPI** (`ciadpi`) под macOS (Apple Silicon M1–M4 / Intel) в виде **полностью автономного приложения** `ByeDPI.app` с автоматическим управлением системным прокси и интеграцией в Launchpad / Spotlight.

## Особенности
- 📦 **Полностью автономный бандл**: всё необходимое (бинарник `ciadpi`, скрипт запуска, файл настроек `config` и иконка) упаковано прямо внутрь `~/Applications/ByeDPI.app`. Никаких лишних скрытых папок в домашней директории!
- 🚀 **Запуск в один клик**: приложение доступно в Launchpad и через поиск Spotlight (`Cmd + Пробел -> ByeDPI`).
- ⚡ **Полная авто-настройка сети**: скрипт сам определяет активное подключение (`Wi-Fi`), включает системный SOCKS5-прокси (`127.0.0.1:1080`), а при закрытии окна терминала — **автоматически выключает прокси и восстанавливает настройки**.
- 🛠 **Простая смена стратегий**: параметры обхода находятся в файле `config` в одну строчку.
- 🔒 **Без root-прав**: не требует `sudo` или установки расширений ядра.

## Установка

Поддерживаются два удобных способа установки:

### Способ 1: Однострочная установка через curl (Рекомендуется)
Не требует предварительного клонирования. Скачивает исходники во временную папку, компилирует бинарник, собирает автономный `ByeDPI.app` в `~/Applications` и подчищает за собой все временные файлы:

```bash
curl -fsSL https://raw.githubusercontent.com/<ваш-аккаунт>/byedpi/master/install.sh | zsh
```

---

### Способ 2: Локальная сборка (через git clone)
Если вы хотите развивать проект или иметь локальный репозиторий:

```bash
git clone --recurse-submodules https://github.com/<ваш-аккаунт>/byedpi.git
cd byedpi
./install.sh
```

---

## Использование

1. Запустите **ByeDPI** из Launchpad или через Spotlight (`Cmd + Пробел` → `ByeDPI`).
2. Откроется окно терминала с мониторингом активных сессий в реальном времени.
3. Открывайте браузер — видео YouTube и заблокированные ресурсы работают на максимальной скорости.
4. Чтобы отключить прокси — просто **закройте окно терминала крестиком** или нажмите `Ctrl + C`.

---

## Настройка стратегии обхода

Активная проверенная стратегия:
```text
-m 2 -d1 -d1+s -r1+s -s3+s -s6+s -s9+s -s12+s -s15+s -s20+s -s25+s -s30+s -s35+s -a1
```

Чтобы отредактировать стратегию в установленном приложении, выполните в терминале:
```bash
open -e ~/Applications/ByeDPI.app/Contents/Resources/config
```
*(Или отредактируйте файл `config` в локальном репозитории и запустите `./install.sh`)*.  
При следующем запуске новая стратегия применится автоматически.

## Удаление

### Быстрое удаление через curl:
```bash
curl -fsSL https://raw.githubusercontent.com/<ваш-аккаунт>/byedpi/master/uninstall.sh | zsh
```

### Удаление из локального репозитория:
```bash
./uninstall.sh
```

Скрипт автоматически:
- Отключит системный прокси macOS и восстановит настройки сети.
- Остановит работающие процессы ByeDPI.
- Удалит бандл `~/Applications/ByeDPI.app`.
