# ByeDPI for macOS (автономный бандл с авто-прокси и интерактивной историей)

Готовая сборка и лаунчер **ByeDPI** (`ciadpi`) под macOS (Apple Silicon M1–M4 / Intel) в виде **полностью автономного приложения** `ByeDPI.app` с автоматическим управлением системным прокси, навигацией по истории стрелками ↑ / ↓ и горячей сменой стратегий «на лету».

## Особенности
- 🚀 **Мгновенный старт**: приложение запускается сразу без задержек и применяет последнюю рабочую стратегию из файла `config`.
- ⌨️ **Навигация по истории стрелками ↑ / ↓**: прямо в окне работающего приложения можно нажимать стрелку **Вверх**, перебирая предыдущие стратегии, редактировать их и применять по `Enter`!
- 📜 **Автоматическая история в `config`**: при вводе новой стратегии она автоматически записывается в конец файла `config` (с автоматическим лимитом хранения до **300 строк**).
- 📦 **Полная автономность**: всё необходимое упаковано прямо внутрь `~/Applications/ByeDPI.app`. Никаких лишних папок в домашней директории!
- 📊 **Чистый интерфейс (только Саммари)**: убран шумный построчный вывод трафика — в окне отображается только красивая статическая сводка со статусом, портом и активной стратегией.
- ⚡ **Полная авто-настройка сети**: скрипт сам определяет активное подключение (`Wi-Fi`), включает системный SOCKS5-прокси (`127.0.0.1:1080`), а при закрытии окна — **автоматически выключает прокси и восстанавливает настройки**.
- 🛡 **Принудительное освобождение порта**: перед каждым стартом скрипт принудительно очищает любые зависшие сокеты и старые процессы.
- 🔒 **Без root-прав**: не требует `sudo` или установки расширений ядра.

## Установка

### Способ 1: Однострочная установка через curl (Рекомендуется)
Не требует предварительного клонирования. Скачивает репозиторий во временную папку, компилирует бинарник, собирает автономный `ByeDPI.app` в `~/Applications` и подчищает за собой все временные файлы:

```bash
curl -fsSL https://raw.githubusercontent.com/<ваш-аккаунт>/byedpi/master/install.sh | zsh
```

---

### Способ 2: Локальная сборка (через git clone)
Если вы хотите развивать проект или иметь локальный репозиторий:

```bash
git clone --recurse-submodules https://github.com/<ваш-аккаунт>/byedpi.git
cd byedpi
./install.sh
```

## Использование и управление стратегиями

### Стандартный запуск:
1. Запустите **ByeDPI** из Launchpad или через Spotlight (`Cmd + Пробел` → `ByeDPI`).
2. Окно терминала **мгновенно запустит прокси** с последней стратегией из `config` и отобразит активное Саммари.
3. Открывайте браузер — видео YouTube и заблокированные ресурсы работают на максимальной скорости.

### Навигация стрелками ↑ / ↓ и смена стратегии на лету:
* Строка ввода изначально пуста (`> `).
* Нажмите клавишу **`↑` (Стрелка вверх)** — появится текущая активная стратегия.
* Нажмите **`↑` ещё раз** — появится прошлая стратегия из истории (и так далее в прошлое по истории).
* Нажмите **`↓` (Стрелка вниз)** — возврат вперед к более новым записям.
* Вы можете отредактировать любую строку (стереть, добавить флаги) и нажать **`Enter`**:
  - Если строка отличается от текущей — она **запишется в конец файла `config`** (до 300 строк), и ByeDPI мгновенно перезапустится с новыми параметрами!
  - Если строка не изменилась или пустая — прокси продолжит работать без перезапуска.

### Выключение:
* Просто **закройте окно терминала крестиком** или нажмите `Ctrl + C`. Системный прокси отключится автоматически.

### Просмотр всей истории стратегий:
```bash
~/Applications/ByeDPI.app/Contents/Resources/run.command --history
```

## Удаление

### Быстрое удаление через curl:
```bash
curl -fsSL https://raw.githubusercontent.com/<ваш-аккаунт>/byedpi/master/uninstall.sh | zsh
```

### Удаление из локального репозитория:
```bash
./uninstall.sh
```

Скрипт автоматически:
- Отключит системный прокси macOS и восстановит настройки сети.
- Остановит работающие процессы ByeDPI.
- Удалит бандл `~/Applications/ByeDPI.app`.
