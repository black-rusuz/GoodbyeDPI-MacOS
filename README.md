# ByeDPI for macOS (автономный бандл с авто-прокси и историей конфигов)

Готовая сборка и лаунчер **ByeDPI** (`ciadpi`) под macOS (Apple Silicon M1–M4 / Intel) в виде **полностью автономного приложения** `ByeDPI.app` с автоматическим управлением системным прокси, интерактивной сменой стратегий и ведением истории.

## Особенности
- 📦 **Полностью автономный бандл**: бинарник `ciadpi`, лаунчер, файл настроек `config` и иконка упакованы прямо внутрь `~/Applications/ByeDPI.app`. Никаких лишних папок в домашней директории!
- 📜 **История стратегий**: файл `config` сохраняет всю историю ваших изменений с датой и временем. Приложение всегда автоматически берет **последнюю активную строку**.
- ⌨️ **Смена стратегии прямо в терминале**: при запуске можно просто вставить готовую строку и нажать Enter — она запишется в историю и сразу применится. Если ничего не нажимать, через 3 секунды сработает автостарт с текущей стратегией.
- 📊 **Чистый интерфейс (только Саммари)**: убран шумный построчный вывод трафика каждого TCP-соединения — в окне отображается только красивая статическая сводка со статусом, прокси-адресом и активной стратегией.
- ⚡ **Полная авто-настройка сети**: скрипт сам определяет активное подключение (`Wi-Fi`), включает системный SOCKS5-прокси (`127.0.0.1:1080`), а при закрытии окна терминала — **автоматически выключает прокси и восстанавливает настройки**.
- 🛡 **Принудительное освобождение порта**: перед стартом скрипт принудительно очищает любые зависшие сокеты и завершает старые процессы.
- 🔒 **Без root-прав**: не требует `sudo` или установки расширений ядра.

## Установка

### Способ 1: Однострочная установка через curl (Рекомендуется)
Не требует предварительного клонирования. Скачивает исходники во временную папку, компилирует бинарник, собирает автономный `ByeDPI.app` в `~/Applications` и подчищает за собой все временные файлы:

```bash
curl -fsSL https://raw.githubusercontent.com/<ваш-аккаунт>/byedpi/master/install.sh | zsh
```

---

### Способ 2: Локальная сборка (через git clone)
Если вы хотите развивать проект или иметь локальный репозиторий:

```bash
git clone --recurse-submodules https://github.com/<ваш-аккаунт>/byedpi.git
cd byedpi
./install.sh
```

---

## Использование и смена стратегий

### Стандартный запуск:
1. Запустите **ByeDPI** из Launchpad или через Spotlight (`Cmd + Пробел` → `ByeDPI`).
2. Окно терминала покажет текущую стратегию:
   - **Чтобы применить новую стратегию:** вставьте новую строчку и нажмите `Enter`. Она автоматически добавится в файл истории `config` и применится.
   - **Чтобы запустить текущую:** просто нажмите `Enter` (или подождите 3 секунды для автозапуска).
3. Экран переключится в режим лаконичного саммари со статусом 🟢 РАБОТАЕТ на порту `1080`.
4. Чтобы выключить прокси — просто **закройте окно терминала крестиком** или нажмите `Ctrl + C`.

### Просмотр всей истории стратегий:
```bash
~/Applications/ByeDPI.app/Contents/Resources/run.command --history
```

### Редактирование истории вручную:
```bash
open -e ~/Applications/ByeDPI.app/Contents/Resources/config
```

## Удаление

### Быстрое удаление через curl:
```bash
curl -fsSL https://raw.githubusercontent.com/<ваш-аккаунт>/byedpi/master/uninstall.sh | zsh
```

### Удаление из локального репозитория:
```bash
./uninstall.sh
```

Скрипт автоматически:
- Отключит системный прокси macOS и восстановит настройки сети.
- Остановит работающие процессы ByeDPI.
- Удалит бандл `~/Applications/ByeDPI.app`.
