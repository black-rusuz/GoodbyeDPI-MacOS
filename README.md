# ByeDPI for macOS

Автономное приложение и интерактивный лаунчер **ByeDPI** (`ciadpi`) для macOS (Apple Silicon и Intel) с автоматическим управлением системным прокси, навигацией по истории параметров клавишами ↑ / ↓ и мгновенным применением изменений.

---

## Возможности

- ⚡ **Мгновенный старт**: сервис сразу применяет последнюю актуальную стратегию из файла конфигурации.
- ⌨️ **Навигация по истории стрелками ↑ / ↓**: перебор и редактирование ранее использованных параметров прямо в окне работающего приложения.
- 🔄 **Горячее применение**: ввод новой стратегии сохраняет её в файл и перезапускает прокси без необходимости перезапускать терминал.
- 📜 **Автоматическое ведение истории**: файл конфигурации хранит последние 300 записей, предотвращая бесконечное разрастание истории.
- 📦 **Полная автономность**: все исполняемые файлы и ресурсы упакованы внутрь бандла `~/Applications/ByeDPI.app` — в домашней директории не создаётся лишних папок.
- 🌐 **Автоматическая настройка сети**: скрипт определяет текущий активный интерфейс (Wi-Fi, Ethernet), включает системный SOCKS5-прокси (`127.0.0.1:1080`), а при закрытии окна корректно возвращает исходные параметры соединения.
- 🛡 **Освобождение порта**: автоматическая проверка и очистка сокетов перед запуском предотвращает ошибку `Address already in use`.
- 📊 **Лаконичный интерфейс**: отсутствие шумного построчного вывода трафика — на экране отображается только наглядная сводка статуса и текущих параметров.
- 🔒 **Безопасность**: работа исключительно в пространстве пользователя, без использования `sudo` или установки сторонних расширений ядра.

## Установка

### Вариант 1. Быстрая установка одной командой (рекомендуется)

Загружает репозиторий во временный каталог, компилирует бинарный файл под архитектуру вашего Mac, собирает бандл `ByeDPI.app` в `~/Applications` и удаляет временные файлы сборки:

```bash
curl -fsSL https://raw.githubusercontent.com/rusuz/byedpi/master/install.sh | zsh
```

---

### Вариант 2. Локальная сборка из репозитория

Подходит для разработки и тестирования локальных изменений:

```bash
git clone --recurse-submodules https://github.com/rusuz/byedpi.git
cd byedpi
./install.sh
```

## Использование

### Запуск приложения

1. Откройте **ByeDPI** через Launchpad или поиск Spotlight.
2. Приложение запустит прокси-сервер с последней рабочей стратегией из `config` и включит системный SOCKS5-прокси macOS.
3. В окне терминала отобразится статусная панель с текущими сетевыми параметрами.

### Навигация и изменение стратегии на лету

В окне работающего приложения доступна интерактивная командная строка:

* Строка ввода изначально пуста (`> `).
* **Стрелка вверх (`↑`)**: подставляет текущую активную стратегию.
* **Повторные нажатия `↑`**: листают историю вглубь к более ранним записям.
* **Стрелка вниз (`↓`)**: возвращает к более поздним записям вплоть до пустой строки.
* **Применение изменений (`Enter`)**:
  - Если введена новая комбинация аргументов — строка сохраняется в конец `config`, а сервис мгновенно перезапускается с новыми параметрами.
  - Если строка пустая или не изменилась — прокси продолжает работу без перезапуска.

### Завершение работы

Для остановки прокси и автоматического отключения системного SOCKS5 достаточно:
- нажать комбинацию клавиш `Ctrl + C` в окне терминала, **либо**
- просто закрыть окно приложения.

### Просмотр истории конфигураций

Для просмотра полного списка сохранённых стратегий выполните:

```bash
~/Applications/ByeDPI.app/Contents/Resources/run.command --history
```

## Удаление

### Удаление одной командой (curl)

```bash
curl -fsSL https://raw.githubusercontent.com/rusuz/byedpi/master/uninstall.sh | zsh
```

### Удаление из локального каталога

```bash
./uninstall.sh
```

Скрипт выполнит:
1. Корректное отключение системного прокси macOS и восстановление сетевых параметров.
2. Остановку фоновых процессов `ciadpi`.
3. Удаление приложения `~/Applications/ByeDPI.app`.
