# ByeDPI for macOS (автономный бандл с авто-прокси и горячей сменой стратегий)

Готовая сборка и лаунчер **ByeDPI** (`ciadpi`) под macOS (Apple Silicon M1–M4 / Intel) в виде **полностью автономного приложения** `ByeDPI.app` с автоматическим управлением системным прокси, горячей сменой стратегий «на лету» и историей изменений.

## Особенности
- 🚀 **Мгновенный старт**: приложение запускается сразу без таймеров и задержек, автоматически применяя последнюю рабочую стратегию.
- 🔄 **Горячая смена стратегий «на лету»**: в любой момент работы приложения вставьте новую строчку стратегии в терминал и нажмите `Enter` — ByeDPI мгновенно перезапустится с новыми параметрами и запишет их в историю!
- 📜 **История конфигураций**: файл `config` хранит всю историю изменений с датой и временем. Приложение всегда берет **последнюю активную строку**.
- 📊 **Чистый интерфейс (только Саммари)**: убран шумный построчный вывод трафика — в окне отображается только красивая статическая сводка со статусом, портом и активной стратегией.
- ⚡ **Полная авто-настройка сети**: скрипт сам определяет активное подключение (`Wi-Fi`), включает системный SOCKS5-прокси (`127.0.0.1:1080`), а при закрытии окна — **автоматически выключает прокси и восстанавливает настройки**.
- 🛡 **Принудительное освобождение порта**: перед каждым стартом скрипт принудительно очищает любые зависшие сокеты и старые процессы.
- 🔒 **Без root-прав**: не требует `sudo` или установки расширений ядра.

## Установка

### Способ 1: Однострочная установка через curl (Рекомендуется)
Не требует предварительного клонирования. Скачивает исходники во временную папку, компилирует бинарник, собирает автономный `ByeDPI.app` в `~/Applications` и подчищает за собой все временные файлы:

```bash
curl -fsSL https://raw.githubusercontent.com/<ваш-аккаунт>/byedpi/master/install.sh | zsh
```

---

### Способ 2: Локальная сборка (через git clone)
Если вы хотите развивать проект или иметь локальный репозиторий:

```bash
git clone --recurse-submodules https://github.com/<ваш-аккаунт>/byedpi.git
cd byedpi
./install.sh
```

---

## Использование и смена стратегий

### Стандартный запуск:
1. Запустите **ByeDPI** из Launchpad или через Spotlight (`Cmd + Пробел` → `ByeDPI`).
2. Окно терминала **мгновенно запустит прокси** и покажет активное Саммари.
3. Открывайте браузер — видео YouTube и заблокированные ресурсы работают на максимальной скорости.

### Смена стратегии во время работы:
* Просто **вставьте новую строку с параметрами в окно терминала** и нажмите `Enter`.
* ByeDPI мгновенно перезапустится с новой стратегией на лету, а строка автоматически сохранится в историю `config`.

### Выключение:
* Просто **закройте окно терминала крестиком** или нажмите `Ctrl + C`. Системный прокси отключится сам.

### Просмотр всей истории стратегий:
```bash
~/Applications/ByeDPI.app/Contents/Resources/run.command --history
```

## Удаление

### Быстрое удаление через curl:
```bash
curl -fsSL https://raw.githubusercontent.com/<ваш-аккаунт>/byedpi/master/uninstall.sh | zsh
```

### Удаление из локального репозитория:
```bash
./uninstall.sh
```

Скрипт автоматически:
- Отключит системный прокси macOS и восстановит настройки сети.
- Остановит работающие процессы ByeDPI.
- Удалит бандл `~/Applications/ByeDPI.app`.
